<h1 align="center">selfh.st Icon Pack</h1>

A little more personality for your workflows! This extension adds **2,386 icons** from the [selfh.st icon collection](https://selfh.st/icons/) to the [xyOps Workflow Automation System](https://xyops.io), including logos for self-hosted apps, services, and other software.

## Features

- Adds the icons directly to the standard xyOps icon picker.
- Displays them in monochrome, inheriting the surrounding text color so they blend in with the built-in Material Design Icons (MDI) in both light and dark themes.
- Serves the icons from your xyOps server, with no external requests needed to display them.
- No configuration required.

## Installation and Usage

Requires xyOps v1.1.3+ with system extension support and an administrator account.

Open the **Marketplace** in xyOps, find **selfh.st Icon Pack**, and follow the installation prompts. The primary conductor restarts after installation to load the extension.

Once loaded, the new icons are available anywhere xyOps offers its standard icon picker. Search for an application name, or search for `selfhst-` to browse this pack. Choose an icon just as you would any built-in icon.
